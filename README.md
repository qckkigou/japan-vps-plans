## 退款条款里的五个坑，下单前必须知道

V.PS 提供 14 天退款保证，VPS 产品在 14 个自然日内提交工单就能申请。但条款里的例外情况比退款本身更值得读，这几条踩中任意一条就拿不回钱：

- **流量超过 10 GB**：14 天内用了超过 10GB 流量，退款资格直接作废。想试线路的人，头几天控制用量。
- **每账号终身只退一次**：这次退了，下次买别的套餐就没有退款保障了。
- **付款方式决定退款资格**：加密货币和银行转账付款一律不退；想保留退款权利就用 PayPal 或信用卡。国内用户注意，官网支持支付宝，但稳妥起见可以考虑 PayPal。
- **动过 IP 就没得退**：申请过 IP 更换的服务不可退款。IP 更换本身也有规则——激活后 24 小时内可免费换 1 次 IPv4，之后每次 €8，每月最多一次。
- **闪购和续费订单不退**：特价 Flash Sale 机器和续费订单均不可退款。

另外下单时有反欺诈审核：需要填真实姓名和常住地址，不能挂 VPN/代理下单，被判定欺诈的订单会直接关闭并原路退回。填假信息省的那点事，会在退款或续费时变成大麻烦。
